# 🍔 Cardápio Online - Gastronomia Artesanal

Um projeto web simples e interativo que simula o cardápio digital de uma lanchonete, permitindo que os usuários selecionem itens e vejam o resumo do seu pedido em tempo real.

## 🚀 Funcionalidades

- **Seleção Dinâmica de Itens:** Clique em qualquer card de lanche para selecioná-lo ou desmarcá-lo.
- **Contador em Tempo Real:** O sistema atualiza automaticamente a quantidade de itens selecionados.
- **Limpeza Rápida:** Botão para limpar todas as seleções atuais de uma só vez.
- **Destaques Visuais:** Estilização especial para itens em destaque no cardápio.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização moderna com efeitos visuais e manipulação de bordas dinâmicas.
- **JavaScript (Vanilla):** Lógica para manipulação do DOM, escutadores de eventos (`addEventListener`) e controle de estado das seleções.
